# CP2K View
[English](README.md) | [简体中文](README.zh-CN.md)

Created by bxyao | ybx20021218@163.com

CP2K View 是一个在浏览器里运行的 CP2K 结构与输出文件可视化工具。它不需要把文件上传到服务器，文件会在本地浏览器中读取，适合查看 CP2K 的结构文件、轨迹文件、输入文件和输出文件。

这个整理后的开源版本，保留原有主要功能，并加入了一些新功能和可维护性改动。

## 和旧版原型相比的新变化

- 旧版主要集中在少数几个大 JS 文件里；新版把代码拆成了多个功能文件，例如文件导入、结构显示、帧控制、测量、OUT 分析、INP 面板、图表窗口、双语文本等，后续别人贡献代码时更容易找到位置。
- 增加中文 / English 界面切换，语言选择会保存在本地浏览器中。
- 增强 CP2K OUT 分析：能显示总览、能量分解、SCF、几何优化、MD、原子类型、文件/参数、晶胞/应力/力、计时、警告和错误等信息。
- 增加 OUT 源码定位功能，可以从分析面板跳到 OUT 文件中的对应行附近。
- 增强结构和 OUT 的自动关联：当只加载一个结构轨迹和一个 OUT 文件时，会尝试把结构帧和 OUT 里的优化步、能量分解、SCF 块对应起来。
- 播放结构帧时，右侧输出分析会跟随当前帧更新，同时避免整块面板连续闪烁。
- SCF 收敛图会跟随当前帧更新，不需要关闭后重新打开。
- 几何优化的四个收敛指标图使用对数方式绘图，便于看清小数值变化；界面上显示的数值仍然保留原始数值。
- **优化能量曲线去掉 CP2K 初猜能量点，让 Step 1 能量和对应的力/步长指标对齐。**
- 趋势图、SCF 图、优化图现在均都支持放大窗口查看。
- 图表窗口支持拖动、缩放、框选局部放大、重置视图、选择最小值点、点选图中数据来同步结构帧。
- 测量功能增强：可以保留当前测量值、导出趋势 CSV，并在多帧结构上显示测量趋势。
- INP / restart 面板增强：可以查看输入文件树、编辑原文、导出编辑后的文件。
- **增加 INP 自定义语句库：可保存本地常用语句、插入到当前光标位置、删除时需要确认。**
- **增加 INP 文件对比：两个 INP/restart 可以左右对比，显示新增、删除、修改，并提供补充、删除、左右覆盖、保存、放大对比等操作。**
- 优化 INP 对比编辑后的滚动位置，避免操作后自动跳回第一行。
- 对较多原子的结构显示做了性能整理，例如化学键推断使用空间分桶，减少大体系反复判断键的压力。
- 增加 `samples/` 示例文件，方便开源用户打开后直接试用。

## 支持的文件

可以通过顶部“打开”按钮导入，也可以把文件拖到页面中。

- `.xyz`：结构或多帧轨迹。
- `.inp`：CP2K 输入文件，可读取 `&COORD` 和 `&CELL`。
- `.restart`：CP2K restart 文件，可按输入结构方式读取。
- `.out` / `.log`：CP2K 输出文件，可解析输出分析信息，也可能读取其中的坐标块。
- `.pdb`：PDB 结构文件。
- `.cif`：包含笛卡尔坐标的 CIF 结构文件。
- `.txt`：会尝试按可识别的结构或文本处理。

## 主要功能

### 结构查看

- 在中央画布中显示原子结构。
- 支持鼠标旋转、缩放、平移结构。
- 支持多帧结构的上一帧、下一帧、播放/暂停、帧滑条和播放速度控制。
- 支持调节原子球大小。
- 支持显示或隐藏元素名称。
- 点击原子后显示元素、类型和坐标。
- 使用接近 Jmol/CPK 风格的元素颜色。
- 根据原子半径和距离自动推断化学键。
- 如果文件里有晶胞信息，可以显示晶胞线框。
- 当前帧可以导出为 XYZ 文件。

### 结构信息

- 显示当前文件名、文件类型、原子数、帧数、当前帧、组成等信息。
- 如果结构已和 OUT 文件关联，可以显示对应的 OUT 文件、优化步、能量、能量分解块、最大步长、RMS 步长、最大梯度、RMS 梯度等信息。
- 导出的 XYZ 注释行会尽量带上当前帧对应的优化指标。

### 原子测量

- 选择 2 个原子：计算键长/距离。
- 选择 3 个原子：计算键角。
- 选择 4 个原子：计算二面角。
- 显示已选择的原子列表。
- 多帧结构中可以显示距离、角度或二面角随帧变化的趋势图。
- 趋势图会标出当前帧。
- 可以打开更大的趋势图窗口。
- 可以保留当前测量值，形成已保留测量列表。
- 可以删除已保留测量。
- 可以导出趋势数据为 CSV。

### CP2K OUT 输出分析

- 读取 `.out` / `.log` 中的 CP2K 输出信息。
- 显示结束状态：正常结束、异常中断或未知。
- 显示 OUT 行数、CP2K 版本、运行类型、项目名、QS 方法、XC 泛函、cutoff、relative cutoff 等总览信息。
- 统计能量点、SCF 运行次数、SCF 记录数、优化步数、MD 步数、警告和错误数量。
- 显示能量分解，包括 core charge overlap、自能、Core Hamiltonian、Hartree、交换相关能、总能量等。
- 显示 SCF 迭代表、收敛值、是否收敛，并能打开 SCF 收敛图。
- 显示几何优化信息，包括优化器、收敛状态、最近优化步和优化曲线。
- 优化曲线包括总能量、最大力、RMS 梯度、最大步长、RMS 步长。
- 收敛指标图用对数方式绘制，便于观察收敛过程；具体数值仍显示真实原值。
- 能量图不显示 CP2K 初猜能量点，用后续优化步与结构帧对齐。
- 支持点击优化图中的点来同步结构帧和分析信息。
- 显示 MD 相关步骤和常见数值，例如时间、温度、动能、势能、守恒量等（测试版）。
- 显示原子类型、元素、数量、基组、赝势等信息。
- 显示 CP2K 输出中识别到的文件记录和参数记录。
- 显示晶胞、力、应力、计时信息。
- 警告和错误会分组显示，方便快速检查重复问题。
- 可以定位 OUT 源文件中的能量块、SCF 块、参数行、警告行和错误行。

### 结构 - OUT 关联

- 当项目里只有一个结构轨迹和一个 OUT 文件时，软件会尝试自动关联。
- 关联后，切换结构帧时，右侧输出分析会跟随当前帧显示对应的能量分解、SCF 块和优化指标。
- 如果 OUT 比结构多一个初始能量/初始 SCF 块，会尝试自动偏移对齐。
- 如果帧数和 OUT 记录数量不完全一致，会给出关联提示。

### CP2K INP / restart 工具

- 读取 `.inp` / `.restart` 文件。
- 提取 `&COORD` 中的原子坐标用于结构显示。
- 提取 `&CELL` 中的晶胞信息用于晶胞显示。
- 以树形方式显示输入文件中的 `&SECTION` 层级和常见参数。
- 可以查看和编辑 INP 原文。
- 可以导出编辑后的 INP/restart 文件。
- 可以保存本地自定义 INP 语句。
- 可以把自定义语句插入到编辑框当前光标处。
- 删除自定义语句前会弹出确认，减少误删。
- 支持比较两个 INP/restart 文件。
- INP 对比可以显示相同、增加、删除、修改的行。
- INP 对比提供补到左、补到右、删左、删右、用左覆盖右、用右覆盖左等操作。
- INP 对比支持保存左侧或右侧编辑后的文件。
- INP 对比支持放大窗口查看。
- 对比窗口中的编辑操作会尽量保持滚动位置。

### 图表窗口

- 测量趋势图、SCF 收敛图、几何优化图都可以在独立大窗口中查看。
- 图表窗口可以拖动和调整大小。
- 支持框选局部放大。
- 支持双击或按钮重置视图。
- 支持选择最小值点。
- 支持键盘左右方向键在图表点之间切换。
- 点击图表点可以同步当前结构帧和分析面板。

### 界面和布局

- 三栏布局：左侧项目文件，中间结构画布，右侧信息面板。
- 左右栏宽度可以拖动调整。
- 可以重置三栏布局。
- 右侧面板分为结构、测量、输出分析、INP 结构。
- 右侧面板可以单独放大查看。
- 支持中文和英文界面切换。
- 语言选择保存在本地浏览器中。

### Multiwfn 辅助（测试版，待完善）

- 可以填写 Multiwfn 程序路径。
- 根据当前结构文件生成类似 `"Multiwfn.exe" "filename"` 的命令。
- 软件只生成命令，不会直接启动 Multiwfn。

## 基本使用

1. 打开 `index.html`。
2. 点击顶部“打开”，或把结构/OUT/INP 文件拖到页面中。
3. 在左侧项目文件列表中切换文件。
4. 在中间画布查看结构，在底部控制帧、播放速度、原子大小和元素标签。
5. 在右侧切换“结构”“测量”“输出分析”“INP 结构”面板。
6. 如果同时加载一个结构轨迹和一个 OUT 文件，软件会尝试自动关联帧和 OUT 分析数据。
7. 需要导出时，可以导出当前帧 XYZ、测量趋势 CSV、编辑后的 INP/restart。

如果直接双击 `index.html` 后浏览器限制了某些本地功能，可以在文件夹下启动一个本地静态服务再访问，例如：

```bash
python -m http.server 8765
```

然后打开：

```text
http://127.0.0.1:8765/
```

## 说明与限制

- 这是一个前端本地工具，主要依赖浏览器运行。
- 文件读取发生在本地浏览器中，**软件本身不会把文件上传到远程服务器**（也没有远程服务器）。
- CP2K OUT 格式很多，不同版本、不同打印级别的 OUT 可能会有差异；目前解析器会尽量识别常见 CP2K 输出（当前测试均基于cp2k202502版本）。
- 化学键是根据元素半径和距离自动推断的，不等同于严格的量子化学键级分析。
- CIF 目前主要读取笛卡尔坐标字段。
- Multiwfn 部分只生成命令，不负责启动外部程序。
- 本地自定义 INP 语句和语言设置保存在浏览器 localStorage 中，换浏览器或清理浏览器数据后可能消失。

## 开发说明

- 主页面：`index.html`
- 样式：`styles.css`
- 功能代码：`src/`
- 示例文件：`samples/`

`src/` 里的主要模块大致如下：

- `app.js`：主流程，把各个模块连接起来。
- `viewer.js`：结构画布、原子颜色、化学键、晶胞、鼠标交互。
- `parsers.js`：XYZ、INP、restart、OUT、PDB、CIF 等文件解析。
- `files.js`：文件导入和项目文件列表。
- `frame-controls.js`：帧切换、播放、速度、球径、元素标签。
- `measurement.js`：键长、角度、二面角和趋势图。
- `saved-measurements.js`：保留测量值。
- `structure-info.js`：结构信息面板。
- `out-analysis-data.js` / `out-analysis-panel.js` / `out-locator.js` / `out-linker.js`：OUT 分析、源码定位、结构 - OUT 关联。
- `input-panel.js`：INP 树、编辑、自定义语句、INP 对比。
- `chart-data.js` / `chart-drawing.js` / `chart-window-frame.js` / `chart-window-content.js` / `optimization-chart-panel.js`：图表数据、绘制和大窗口。
- `layout.js` / `inspector-panels.js`：三栏布局和右侧面板。
- `i18n.js`：中英文界面文本。
- `utils.js`：通用小工具。
