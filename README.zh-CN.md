# cp2kview-demo

`cp2kview-demo` 是一个轻量级、基于浏览器的 CP2K 结构与输出文件可视化工具。该项目完全由个人独立开发，目前作为 demo 版本开源发布，方便大家测试和交流。

应用完全在浏览器中运行，用户无需安装任何项目依赖即可使用。日常使用不需要后端服务，也不需要构建步骤。

当前版本主要面向结构快速查看、CP2K 输入/输出解析、轨迹播放、几何测量、结构优化分析，以及简单的 Multiwfn 命令生成。

## 功能特性

- 打开本地 `xyz`、`inp`、`out`、`restart`、`pdb`、`cif`、`log` 和普通文本类文件。
- 解析多帧 XYZ 轨迹。
- 从 CP2K `&COORD` 段和 CP2K 输出坐标块中提取结构。
- 使用 Canvas 查看结构，支持旋转、缩放、平移、元素标签、帧切换和轨迹播放。
- 根据共价半径自动推断简单化学键，并使用 JMol/CPK 风格元素配色。
- 通过点选原子测量键长、键角和二面角。
- 绘制测量值随轨迹帧变化的趋势图，并导出 CSV。
- 将 CP2K 输入文件和 restart 文件解析为可展开的 `&SECTION` 树。
- 分析 CP2K 输出文件中的元信息、能量、SCF 记录、几何优化步、MD 记录、原子类型、计时、警告、错误和结束状态。
- 当同时加载一个结构轨迹和一个 CP2K 输出文件时，尝试把轨迹帧与结构优化步关联起来，并在每帧显示优化指标。
- 绘制结构优化指标图，包括总能量、步长和梯度信息。
- 将当前帧导出为 XYZ 文件。
- 为当前选中的结构文件生成 Multiwfn 启动命令。

## 运行要求

- 现代桌面浏览器，例如 Chrome、Edge、Firefox 或 Safari。
- 日常使用不需要安装任何项目依赖。
- 如果希望通过 `localhost` 访问，可以使用 Python 或其他静态文件服务器。

## 快速开始

### 方式一：直接打开 HTML 文件

用浏览器打开：

```text
app/index.html
```

打开后点击右上角的 **打开** 按钮，或者把文件拖入页面。

### 方式二：启动本地静态服务

在仓库根目录执行：

```bash
cd app
python -m http.server 8000
```

然后在浏览器访问：

```text
http://localhost:8000
```

如果浏览器或本机安全策略对 `file://` 页面限制较严格，推荐使用这种方式。

## 基本使用方法

1. 直接打开 `app/index.html`，或启动本地静态服务。
2. 点击 **打开** 按钮加载结构文件或 CP2K 文件，也可以直接拖拽文件到页面中。
3. 通过左侧文件列表在已加载文件之间切换。
4. 在中间的结构查看器中观察原子和轨迹帧。
5. 在右侧面板查看结构信息、几何测量、CP2K 输出分析和 CP2K 输入/restart 树。

`app/` 目录中自带的 `.xyz` 和 `.out` 文件可以用于第一次测试。

## 查看器操作

- 鼠标左键拖拽：旋转结构。
- 鼠标滚轮：放大或缩小。
- 鼠标右键拖拽、`Ctrl` + 拖拽或 `Alt` + 拖拽：缩放。
- `Shift` + 拖拽或鼠标中键拖拽：平移。
- 点击原子：选择原子用于测量。
- 选择 2 个原子：测量距离。
- 选择 3 个原子：测量角度。
- 选择 4 个原子：测量二面角。
- 左/右方向键：切换轨迹帧。
- 空格键：播放或暂停轨迹。
- 帧滑块：跳转到指定帧。
- 速度滑块：调整播放速度。
- 球径滑块：调整原子球大小。
- 元素名开关：显示或隐藏元素标签。

## CP2K 输出分析

加载 CP2K `.out` 或 `.log` 文件后，可以在输出分析面板查看解析结果，包括：

- CP2K 版本和运行元信息。
- 输入文件、项目名、运行类型、输出级别和部分 DFT 设置。
- 能量记录。
- SCF 收敛记录。
- 几何优化状态和最近的优化步。
- 检测到的 MD 步信息。
- 原子和 kind 信息。
- 计时记录。
- 警告、错误、异常终止标记和正常结束标记。

如果同时只加载了一个结构轨迹和一个 CP2K 输出文件，CP2K View 会尝试把轨迹帧和几何优化步对齐。对齐成功后，结构面板和优化图中会显示每帧对应的能量与收敛指标。

## 数据导出

- **导出 XYZ**：把当前显示的帧保存为 `.xyz` 文件。
- **导出 CSV**：在测量面板中导出当前键长/键角/二面角随轨迹帧变化的趋势数据。

## Multiwfn 命令助手

Multiwfn 面板会生成类似下面的命令：

```bash
"Multiwfn.exe" "structure.xyz"
```

你可以在输入框中修改 Multiwfn 可执行文件路径。当前功能只负责生成命令，浏览器不会直接启动 Multiwfn。

## 说明与限制

- 这是一个纯前端原型，选择的文件会通过浏览器 File API 在本地读取。
- CP2K 输出格式会受版本、计算类型和打印设置影响，部分坐标块或分析记录可能暂时无法识别。
- 化学键显示基于共价半径启发式推断，适合辅助查看，不应作为严格化学判据。
- CIF 支持目前主要针对笛卡尔坐标。
- Multiwfn 集成目前只提供命令生成。
